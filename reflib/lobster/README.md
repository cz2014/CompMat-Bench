## Scope and provenance

The download agreement accepted by every LOBSTER user states that the software or any part of it shall not be made accessible to third parties without the explicit written consent of the Chair of Solid-State and Quantum Chemistry, RWTH Aachen University, and the guide and FAQ are distributed only inside that download (the official site links no manual). The manuals are therefore not redistributed. The public release carries `MANUALS_NOT_INCLUDED.md` in this directory with the file names, sizes and sha256 values so that a reader with their own licensed copy can restore it. No executable, licence credentials or personal registration data is included. Both PDFs and their staged text extracts are preserved byte-for-byte in this private library.

Counts and sizes cover every file in this code directory except this README. MB means 1,000,000 bytes. No size ceiling applies. `pulled` records collection into this library; earlier source-mirror dates are stated separately.
